# Personal Portfolio

A modern and minimal personal portfolio website built to showcase my work, skills, and projects as a Frontend Developer.

## ✨ Features

- Responsive design
- Dark / Light mode
- Minimal and modern UI
- About section
- Skills section
- Projects showcase
- Contact section
- Social links
- Responsive layout for mobile, tablet, and desktop

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
